# 단어 행성 탐험대

Duolingo English Test(DET)를 준비하는 초등학생을 위한 영어 단어 500개 암기 게임입니다.
Duolingo와 관련 없는 개인 학습 프로젝트입니다.

## 기능

- 10개 행성에서 단어를 되찾는 이야기와 탐험 지도
- 적립금: 퀴즈 단계 18원, 보스 300원, 만점 30,000원 (틀리면 18원 감점, 게임 안의 숫자)
- DAY별 50장 플래시카드: 이미지, 미국식 발음, 눌러서 보는 뜻과 예문
- 하루 미션과 간격 반복 복습
- 뜻 맞히기, 짝 맞추기, 진짜 단어 찾기(5초), 문장 빈칸 채우기(20초), 듣고 쓰기, 실전 모의
- 보호자 화면: 진행률, 자주 틀린 단어, 시험 날짜, 기록 백업과 복원

학습 기록은 사용하는 브라우저에 저장됩니다. 보호자 화면에서 동기화 코드를 만들면 같은 코드를 입력한 기기끼리 기록을 합칩니다. 이때 학습 기록이 Supabase 서버에 저장되며, 이름과 이메일은 받지 않습니다. `game/sync.js`의 키는 공개용(publishable) 키이고, 서버 설정은 `tools/sync.sql`에 있습니다.

## 실행

`game/index.html`을 브라우저로 엽니다. 설치할 것은 없습니다.

## 폴더

- `game/`: 게임 본체 (`main`에 올리면 GitHub Pages로 자동 배포)
- `tools/validate.py`: 단어 데이터 검사
- `조사결과.md`: DET 시험과 유사 서비스 조사

## 권리 안내

- **단어와 뜻:** 시중 교재의 기출 어휘 목록을 바탕으로 입력했으며, 권리는 해당 출판사에 있습니다. 권리자의 요청이 있으면 삭제합니다.
- **예문, 해석, 가짜 단어, 코드:** 이 프로젝트에서 새로 작성했습니다.
- **음성:** `game/audio/`의 음성 파일은 오픈소스 음성 모델 [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)(Apache 2.0, 미국식 음성 af_heart)로 만들었습니다. 사람이 녹음한 음성이 아닙니다.
- **이미지:** Wikimedia Commons 등의 자유 이용 이미지이며 크기를 줄여 사용했습니다. 작가와 라이선스는 카드 아래와 `game/credits.html`에 표시합니다. 각 이미지는 원래 라이선스를 따릅니다.
